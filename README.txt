CHECKUP AI MOBILE v0.3
Prototyp testowy PWA dla iPhone/iOS.

Zmiany:
- mikrofon: pomiar przez 5 sekund, wskaźnik poziomu sygnału; cichy sygnał nie przesądza o usterce
- bateria: brak wartości NaN; gdy API nie jest dostępne, wyświetlany jest czytelny komunikat
- raport: wersja v0.3, bardziej czytelne szczegóły i brak pustych komórek
- service worker: nowy identyfikator pamięci podręcznej v0.3

Aktualizacja na GitHubie:
1. Rozpakuj ZIP w aplikacji Pliki.
2. W repozytorium wybierz Add file -> Upload files.
3. Wgraj pliki z rozpakowanego folderu do katalogu głównego repozytorium i potwierdź zastąpienie istniejących plików.
4. Kliknij Commit changes.
5. Poczekaj na aktualizację GitHub Pages i odśwież aplikację.

Uwagi:
- Mikrofon wymaga HTTPS i zgody. Podczas testu mów przez około 5 sekund.
- Poziom sygnału nie jest laboratoryjnym pomiarem jakości mikrofonu.
- iOS może nie udostępniać poziomu baterii przeglądarce. Brak danych nie oznacza uszkodzenia baterii.
- Raport zapisuj przez Drukuj / Zapisz jako PDF w menu iOS.
